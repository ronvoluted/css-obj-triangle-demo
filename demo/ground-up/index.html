A cube, from the ground up


scroll ↓

1

Here's a div

<div class="panel"></div>
2

Make it a triangle

background: /* solid on one half, clear on the other */ linear-gradient(to bottom right, hotpink 50%, transparent 50%);
3

Rotate it… nothing happens?

transform: rotateY(40deg); /* scene has NO perspective yet → looks 2D */
4

Add perspective

/* on the .scene, the camera lens: */ .scene { perspective: 800px; }
5

Pair them into a square

/* two triangles, two matrix3d() transforms */ .t1 { transform: matrix3d(…) } /* upper-left */ .t2 { transform: matrix3d(…) } /* lower-right */
6

Two more for an adjacent side

/* the parent keeps everything in one space */ .mesh { transform-style: preserve-3d; }
7

Eight more → a whole cube

/* 12 triangles = 6 faces = 1 cube */
8

Spin the whole thing

.mesh { animation: spin 14s linear infinite; } /* a real OBJ mesh is just this, many more times */

That's the entire trick.
